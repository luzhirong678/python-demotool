# 小学数学题生成器

这是一个使用 PyQt5 开发的小学数学题生成器，具有以下功能：

1. 带 UI 界面
2. 用户可以自定义数字范围
3. 确保不会出现负数结果

## 如何运行

### 前提条件

1. 安装 Python 3.6 或更高版本
2. 安装 PyQt5 库

### 安装步骤

1. 安装 Python：
   - 访问 https://www.python.org/downloads/ 下载并安装 Python
   - 确保在安装过程中勾选 "Add Python to PATH"

2. 安装 PyQt5：
   ```
   pip install PyQt5
   ```

3. 运行程序：
   ```
   python main.py
   ```

## 使用说明

1. 在输入框中输入数字范围（1-1000）
2. 点击 "生成题目" 按钮
3. 系统会生成 20 道加减法题目，确保结果不为负数
4. 题目会显示在下方的文本框中

## 代码说明

- `main.py`：包含完整的代码实现
- 使用 PyQt5 创建 GUI 界面
- 随机生成加减法题目
- 确保减法结果不为负数
- 确保加法结果不超过用户设定的范围
